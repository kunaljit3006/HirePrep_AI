# HirePrep_AI logo kit

## Files
- `hireprep-ai-dark.svg` — primary logo for dark backgrounds
- `hireprep-ai-light.svg` — primary logo for light backgrounds
- `hireprep-ai-mono-dark.svg` — one-color dark version
- `hireprep-ai-mono-light.svg` — one-color light version
- `hireprep-icon-dark.svg` / `hireprep-icon-light.svg` — compact developer mark
- `hireprep-ai-dark.png` / `hireprep-ai-light.png` — transparent PNG exports
- `hireprep-icon-dark.png` / `hireprep-icon-light.png` — transparent icon exports
- `logo-preview.png` — presentation preview

## Brand colors
- Terminal green: `#00E382` (gradient range `#00F08A` → `#00D97A`)
- Carbon: `#0A0A0A`
- White: `#FFFFFF`

## Usage
Keep clear space around the logo equal to the width of one vertical terminal bar. Do not stretch, recolor, outline, rotate, or add effects. SVG is the master format and stays crisp at every size.
